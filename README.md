"# pc-monitoring-tool" 

DevOps Monitoring Tool Project
Skills: Python, psutil, logging, cronjobs, Prometheus/Grafana (Potentially)
What it does: Monitors system metrics like CPU, RAM, disk usage, logs errors. Transfers data through API with cloud to display data on a dashboard through a website, concurrent monitoring of computers
Stretch: Send alerts via email or Slack, visualize with Grafana.
